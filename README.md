# POV Waterfall Projection Mapping

## Overview

TouchDesigner script that outputs 3 projections to a scrim placed in front of the POV window. The media contains Test Files, and the capability to present alternate media files. Masking for rock formations hanging in front of the waterfall. Additionally a second output will drive the sculpture at the far end of the atrium. It is possible to drive the media for all four projectors from a single computer. 

## Environment

TouchDesigner `2025.31760` Commercial (Educational license should work as well)

## Settings

- Test Media settings exist in the /project1 > Settings parameters. 
- Edge Blend settings exist in the Edge Blend BASE > Settings panel.
